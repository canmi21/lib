# Roadmap

Where the library is going, without the steps. What is not done is an RFC -- the workspace's
`spec/planning.md`.

- **A package proves itself in production before it is published**, and then joins this repository --
  the workspace's `spec/architecture/layers.md`, "A package is named for what it is, and published
  once it has proved itself".
- **`axum-governor` grows by release**, each one's scope in
  [axum-governor/releases.md](axum-governor/releases.md).
